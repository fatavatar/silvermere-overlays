# Ashfall Valley (levels 55–80)

A sunken valley under the Volcano: a fern basin full of dinosaurs that should have died out,
tar pits ruled by a Tyrannosaur, and the Coiled Temple, where a serpentkin cult breeds raptors
for the Coil Mother. This is area 1 of [`docs/content-areas.md`](../docs/content-areas.md), written as a
silvermere content overlay (silvermere's `docs/overlays.md`). It loads after `mudrev`.

New content for the Realm of Legends. Its dinosaurs, giant locust, scarab swarm and the Viperhide
armour set are MudRev records that no room ever used; the rest is original.

## Applying it

```
silvermere overlay check ashfall-valley     # safe while the server runs
silvermere overlay apply ashfall-valley     # stop the server first
```

A re-import of the realm puts back the realm's own records (the Volcano room and the retuned
monsters), so list the overlay in `content.overlays` (or pass `--overlay ashfall-valley`).
Applying again is safe: what is already in place is reported unchanged.

## The quest: the Coiled Temple

Tamsin, at the ranger's camp, keeps the step in ability 210 (an unnamed code, as the realm keeps
its own quest markers 200–203).

1. **ask tamsin cult** (level 55+): she asks for a cult priest's serpent sigil.
2. **ask tamsin sigil** with the sigil: she splits it and gives the obsidian serpent key
   (25,000,000 experience).
3. **use obsidian serpent key north** at the Antechamber, then kill the Coil Mother.
4. **ask tamsin mother**: the Viperhide Tunic and 60,000,000 experience.

## How it was checked

- `silvermere overlay check`: every exit, monster, item, spell, message and text it points at
  exists.
- **Survival.** MME's model (`tools/area-survival/zone.mjs`) was run against the realm's
  characters:
  - Fern basin: the level 54 character survives most of it, the level 69 character all of it.
  - Tar pits, brood pens and temple hall: about 85–100% survivable from levels 76–77.
  - Tyrannosaur: solo from 76.
  - Coil Mother: solo from about 100; at 70–80 she is a fight for a small party.
- **In game.** It was applied to a copy of the realm and walked in a test server: the way down,
  the rooms, Tamsin's greeting and topics, the sigil turn-in, the key door, the Coil Mother's
  death advancing the quest and dropping the helm, and the tunic at the end.

Not yet on the live realm.
